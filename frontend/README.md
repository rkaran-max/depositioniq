# DepositionIQ Frontend

Next.js frontend for DepositionIQ, built as a polished legal AI product surface.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui-style primitives
- lucide-react icons
- framer-motion

## Run Locally

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```

## Notes

This frontend uses realistic mock data based on a Bill Gates deposition excerpt
covering email retention, document preservation, DR DOS communications,
contradiction risk, and cross-examination targets. The existing Python/Streamlit
backend remains untouched.
